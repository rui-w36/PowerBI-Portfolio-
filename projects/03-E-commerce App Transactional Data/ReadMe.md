# 🛍 From Click to Chart: Business & Consumer Behavior E-commerce Analysis
## Project Overview
This project conducts in-depth e-commerce business and customer consumer behavior analysis based on real transactional datasets. Raw data is processed and cleaned by SQL, then visualized and explored via interactive Power BI dashboard. The research covers business KPI performance, time trend, regional contribution, user life cycle, user retention & churn, user portrait segmentation, APP user journey and payment failure influencing factors, providing comprehensive data insights for e-commerce operational decision-making.

---

## 🎯 Business Objectives
1. Monitor core business KPI performance and long-term time trends
2. Analyze regional GMV contribution and market distribution characteristics
3. Explore user life cycle rules, weekly retention and churn structure
4. Build user portrait and implement user group segmentation analysis
5. Restore APP full-link user behavior journey
6. Identify key influencing factors of payment failure and propose optimization directions

---

## 📊 Dataset Information
- **Data Source**: Kaggle Transactional E-commerce Dataset
🔗 https://www.kaggle.com/datasets/bytadit/transactional-ecommerce
- **Time Span**: July 2016 — July 2022
- **Data Processing Tool**: SQL
- **Data Preprocessing**: Duplicate value removal, abnormal value detection and cleaning

---

## 🧩 Analysis Content & Module Structure
1. **Business Performance Dashboard**
   - Four core KPIs: GMV, Total Banners, Order Volume, Average Order Value
   - Time trend analysis of four KPI indicators (line chart)
   - Regional GMV contribution distribution (map visualization)

2. **User Life Cycle Analysis**
   - Three-stage user life cycle diagram with hover user portrait analysis
   - Weekly user retention heatmap
   - Churn user proportion analysis (bar chart)
   - User segmentation distribution: RFM bubble chart & user group proportion

3. **User Journey Analysis**
   - Full-path behavior track of users using the APP
   - Behavior sequence and conversion path analysis

4. **Influencing Factor Analysis**
   - Root cause exploration and factor sorting of payment unsuccessful events

## 🧠 Analytical Methods
- SQL-based data cleaning: duplicate & outlier handling
- Core business KPI construction and trend analysis
- Regional spatial distribution analysis
- User life cycle & cohort retention analysis
- User churn proportion statistical analysis
- RFM user segmentation & portrait profiling
- APP user behavior journey sorting
- Correlation analysis of payment failure influencing factors

---

## 💡 Business Recommendations
- Formulate targeted operational strategies according to KPI time trend fluctuations
- Increase resource investment in high GMV contribution regions and optimize low-contribution markets
- Improve user retention by optimizing experience for key life cycle stages
- Launch precise marketing campaigns based on segmented user portraits
- Optimize APP operation links to simplify user journey and improve conversion rate
- Rectify key negative factors causing payment failure to reduce transaction loss
